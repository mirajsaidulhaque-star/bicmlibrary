Mojlish Online Library (মজলিস অনলাইন লাইব্রেরি)
	
An online library platform designed to help students research, study Islamic topics, and access educational reading materials effortlessly. Developed by Saidul Haque Miraj.

About the Project

Mojlish Online Library is open to everyone, but it is specifically crafted for students who want to research, study, and gain proficiency in Islamic knowledge while spreading the truth globally. The primary goal of this platform is to provide students with easy access to resource materials, articles, and downloadable books across a wide variety of subjects.

The Mojlish Online Library website features an extensive, categorized book library covering topics like Aqeedah, history, and Seerah, complete with direct online reading and PDF downloading options. It includes a structured syllabus navigation menu tailored for different student levels, an interactive "Self-Introspection" tool that cycles through reflection questions, and a dedicated section for articles. Built with a fully responsive teal-themed UI, the platform leverages custom CSS animations, Bengali typography, and Font Awesome icons to deliver a seamless, accessible user experience across all devices.
